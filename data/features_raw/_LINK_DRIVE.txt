CARA PASANG
-----------
1. Unduh zip yang dibutuhkan.
2. Ekstrak ke folder ini (data/features_raw/), sehingga menjadi:

     data/features_raw/copernicus/era5land/instant/*.nc
     data/features_raw/copernicus/era5land/accum/*.nc
     data/features_raw/copernicus/cems_fire/*.nc
     data/features_raw/nasa/mcd64a1/*.hdf
     data/features_raw/static/{hansen,worldcover,dem,osm,...}/

   Jangan mengubah nama folder; kode mencari path persis seperti itu.

3. Verifikasi isi (opsional, disarankan setelah unduh besar):

     cd hotspot_crawler
     python verify_data.py

   Hasil yang benar:

     ok       : 4135
     mismatch : 0
     missing  : 0
     SEMUA COCOK dengan manifest.

   Jika muncul mismatch/missing, unduh ulang berkas yang disebut.
